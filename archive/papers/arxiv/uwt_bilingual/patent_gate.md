This file coordinates the UWT arXiv submission with the narrower patent path:

> **Computer-implemented relational simulation and prediction using compensated
> relation dynamics.**

The arXiv paper should publish the scientific theory. Patent filing, if pursued,
should protect concrete computational methods rather than the broad relational
theory itself.

## Decision

- UWT should proceed to arXiv as a scholarly foundation and defensive publication.
- UWT should also have one narrow provisional track if the paper or public demos
  disclose concrete simulation/prediction mechanics.
- Broad claims to "relations-first space-time" should not be the patent focus.
- The patent focus should be practical computer-implemented relation dynamics:
  finite relational state, compensated updates, stability metrics, forecast
  generation, and reproducible outputs.

## Safe For arXiv First

These items are appropriate for the UWT paper without waiting for a utility
patent, assuming no hidden implementation details are added:

- Ontological framing: whole, parts, distinguishability, relations.
- Axioms and derived structures: distance, time, motion, mass, energy.
- Relative consistency via a finite model.
- Conceptual comparison with space-time-first theories.
- High-level statement that modeling exists in `uwt_modeling`.
- Negative or limiting scientific results, such as unresolved wavefunction
  dispersion constraints.

## File First Or Remove From arXiv

If the UWT paper, appendix, website, or demo includes these details, file the
narrow provisional first or move them out of public materials:

- Step-by-step relation-state update algorithm with compensated dynamics.
- Concrete forecast/prediction pipeline from relational histories.
- ACT/Balansis compensation telemetry used as control input.
- Stability-width or wavefunction calibration method claimed as predictive.
- UWT-to-MagicBrain substrate-control bridge.
- Benchmark tables showing a practical technical effect of a specific algorithm.
- Source-code-level pseudocode that enables replication of the applied method.

## Publication Order

1. Freeze the UWT arXiv PDF/source.
2. Review for patent-enabling computational detail.
3. If only theory is disclosed, submit UWT to arXiv.
4. If applied simulation/prediction details are disclosed, file the provisional
   package first.
5. After filing, the arXiv paper may mention the filed computational method at a
   high level without exposing trade-secret calibration details.
