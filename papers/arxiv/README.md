# arXiv preparation workspace

This directory contains arXiv-oriented submission packages for Unified Whole Theory
(UWT). arXiv currently requires multilingual submissions to include a complete
English version first, followed by the non-English version.

## Packages

- `uwt_bilingual/` — bilingual English/Russian UWT preprint package.

## Submission policy notes

- Use TeX/LaTeX source, not a PDF generated from TeX.
- Put the English version first and the Russian version second.
- Use ASCII-safe metadata in arXiv fields; keep Cyrillic inside the PDF body.
- Upload only files needed to compile the paper.
- Select XeLaTeX for bilingual Cyrillic/Latin sources.
