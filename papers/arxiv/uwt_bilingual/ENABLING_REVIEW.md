доказательствами и программу исследований — ни одного пункта из списка
«File First Or Remove».

## Проверка по 7 критериям «File First Or Remove»

1. Пошаговый алгоритм обновления с компенсированной динамикой — **отсутствует**
2. Конкретный forecast-пайплайн из реляционных историй — **отсутствует**
3. ACT/Balansis-телеметрия как control input — **отсутствует** (Balansis/АКТ не упоминаются вовсе)
4. Предиктивная калибровка stability-width/wavefunction — **отсутствует** (ψ упомянута только в программном пункте (v))
5. UWT-to-MagicBrain bridge — **отсутствует** (MagicBrain не упоминается)
6. Benchmark-таблицы технического эффекта — **отсутствуют**
7. Pseudocode уровня исходников — **отсутствует**

Утечек патентного ядра ACT / MagicBrain / MetaMind в тексте нет.

## Важные оговорки за пределами main.tex

1. **Гейт распространяется на репозиторий и сайт**, не только на статью. Пакет
   `modeling/` СОДЕРЖИТ enabling-реализацию (пошаговые компенсированные
   обновления, forecast-пайплайн, калибровка stability-width) — на 2026-07-13
   репозиторий GitHub приватен (анонимно 404), поэтому раскрытия нет. **До
   открытия репозитория** необходимо либо подать provisional
   («Computer-implemented relational simulation…»), либо принять осознанное
   решение о defensive publication.
2. Заметка о негативных результатах (`papers/notes/negative_results_wavefunction_arrow.md`)
   выдержана на уровне результатов (SAFE-категория «Negative or limiting
   scientific results») — без алгоритмов и калибровочных рецептов.
3. Вывод по Publication Order гейта: выполняется ветка **шага 3** — «If only
   theory is disclosed, submit UWT to arXiv» (при условии, что репозиторий
   остаётся приватным до решения по provisional).
